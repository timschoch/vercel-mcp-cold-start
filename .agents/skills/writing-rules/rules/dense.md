# Dense, only an agent reads it

CLAUDE.md, AGENTS.md, skill files, agent docs. Where plain and dense could both apply, dense wins.

- 601 Imperative. "Run X", not "you should run X". No hedging.
- 602 Only what the code does not say itself. Link, never repeat.
- 603 Short lines, four sentences maximum per paragraph. Density, never obscurity: groups 1 and 2 still hold.
