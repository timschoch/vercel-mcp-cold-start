# Naming

Good defaults, not law — the developer's word overrides anything here.

Before you name a variable, function, file, type, component, table, route, event, or env var, read [naming](.agents/skills/naming/SKILL.md) in full and apply it. Same when the request's word differs from the repo's word.

The `naming` PR gate checks the machine-checkable part on every changed file. Exceptions and overrides: see [Per-project overrides](.agents/skills/naming/SKILL.md#per-project-overrides).
